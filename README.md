# Smart Crossword Learning Web App

Ứng dụng web học từ vựng tiếng Anh qua giải ô chữ (Crossword) tự động.

## Tính năng chính:
- Tự động sinh lưới Crossword từ tối thiểu 15 từ vựng bất kỳ.
- Chấp nhận toàn bộ ký tự đặc biệt: dấu cách (`ice cream`), gạch nối (`apple-pie`, `mother-in-law`, `well-known`), dấu câu.
- Tự động lưu thành các bài tập ôn luyện theo ngày tháng năm (`DD/MM/YYYY`) hoặc cho phép đổi tên tuỳ ý.
- Giao diện trực quan chia cột: Bảng Crossword bên trái và danh sách câu hỏi Gợi ý (Across/Down) kèm ô gạch dưới (`_ _ _ _`) bên phải như ảnh mẫu.
- Chức năng kiểm tra bài làm, chấm điểm, xem đáp án, làm lại từ đầu và in/xuất PDF.

## Khởi động:
```powershell
npm start
```
Truy cập: `http://localhost:3000`
